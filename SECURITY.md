# Security Policy

## Supported versions

This repository is currently under active development. Please report vulnerabilities for the current main branch.

## Reporting a vulnerability

Please report security issues privately by opening a security advisory through GitHub or by contacting the repository maintainers through the project’s GitHub settings.

Do not disclose vulnerabilities publicly until a fix is available or a coordinated disclosure window has been agreed.

## Security expectations

- Prefer fail-closed behavior over permissive defaults.
- Prevent credential leakage in logs, prompt payloads, and artifacts.
- Keep provenance, approval, and audit controls intact.
